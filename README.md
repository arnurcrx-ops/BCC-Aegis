# BCC Aegis

Локальная VoIP-лаборатория на базе **Docker** и **Asterisk 22** с мостом **ARI (`ari-bridge`)**, бэкендом **FastAPI** и модулем антифрод-скоринга для звонков и контроля исходящей активности.

## Архитектура

* **`asterisk`** (`andrius/asterisk:22`) — SIP/PJSIP-сервер и обработка голосового трафика (RTP).
* **`ari-bridge`** — связывает события Asterisk (ARI) с логикой скоринга и аудита.
* **`backend`** — API/сервис аналитики, правил и журналов вызовов.
* **`setup.py` + `.env`** — генерация конфигураций PJSIP/диалплана и параметры окружения.

## Быстрый старт

### Требования
* Docker и Docker Compose
* Python 3.x

### Запуск

1. Создайте `.env` на основе примера и заполните ключи/параметры сети (`LAN_IP`, пароли экстеншнов и т.д.).
2. Сгенерируйте конфиги и поднимите сервисы:

```bash
python setup.py
docker compose up -d --force-recreate
```

3. Проверьте состояние контейнеров и регистрацию SIP-клиентов:

```bash
docker compose ps
docker compose exec asterisk asterisk -rx "pjsip show contacts"
```

## Основные настройки (`.env`)

| Переменная | Назначение |
| :--- | :--- |
| `LAN_IP` / `LAN_BIND_IP` | IP хоста в локальной сети и адрес биндинга для LAN-трафика |
| `ENFORCE` | Включение жёсткой блокировки при срабатывании антифрод-правил (`true` / `false`) |
| `TRUNK_ENABLED` | Включение внешнего SIP-транка (`true` / `false`) |
| `ALLOWED_PREFIXES` | Разрешённые префиксы номеров для исходящих вызовов |
| `OUTBOUND_MAX_PER_HOUR` | Лимит исходящих вызовов в час |
| `NIGHT_START` / `NIGHT_END` | Ночное окно (часы) с учётом `LOCAL_UTC_OFFSET` |

## Частые проблемы

* **`pjsip show contacts` показывает `No objects found`** — после пересоздания контейнера SIP-клиенты ещё не отправили свежий `REGISTER` либо не зарегистрированы в приложении (проверьте сеть/IP, пароль в `.env` и параметры прокси/порта).
* **Звонок не уходит в сеть** — проверьте `TRUNK_ENABLED`, учётные данные транка и правила маршрутизации.

## Безопасность

* Не коммитьте `.env`, API-ключи и пароли экстеншнов в публичный репозиторий.
* После тестов или случайной засветки секретов перегенерируйте ключи и пароли.
